# Hytale Modpack Installer
---
**THIS IS ALL AI CODE**\
This is a fairly complex PS script for handling downloading Hytale mods from Curseforge, indexing them, putting them into your mods folder, and setting up a world with all the mods enabled and include any pre-made configs for newly installed mods. It does also handle updating modpacks too, even if you downgrade a mod itll handle that. This **does not** handle multi-instance however, so keep that in mind that your mods folder should be empty to start with.\
This doesnt bypass anything with Curseforge, downloads will be counted, if the user is already logged into their account they stay logged in when doing these downloads. I'm just opening a new window in the user's default browser and closing that window after all the downloads have been completed.
